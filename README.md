# Dulitha Prasanna Kulathunga

**Website: [dulithaprasanna.github.io](https://dulithaprasanna.github.io)**

Personal academic website of Dulitha Prasanna Kulathunga, Postdoctoral Research Associate in the Department of Pharmacology at the University of North Carolina at Chapel Hill. My research focuses on data-efficient discovery with active machine learning, Bayesian optimization, and biophysics.

## Editing this site

| What                  | Where                                                |
| --------------------- | ---------------------------------------------------- |
| Home page and bio     | `_pages/about.md`                                    |
| CV (web page and PDF) | `_data/cv.yml`                                       |
| Publications          | `_bibliography/papers.bib`                           |
| Projects              | `_projects/`                                         |
| News items            | `_news/` (then enable in `about.md`)                 |
| Blog posts            | `_posts/` (then set `nav: true` in `_pages/blog.md`) |
| Social links          | `_data/socials.yml`                                  |
| Site settings         | `_config.yml`                                        |

Every push to `main` rebuilds and deploys the site through GitHub Actions.

Preview locally with Docker: run `docker compose up`, then open <http://localhost:8080>.

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme (MIT license). Setup and customization guides: [INSTALL.md](INSTALL.md), [CUSTOMIZE.md](CUSTOMIZE.md), [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
